# 📑 Documentação Técnica ( docs/ )

## 📌 Introdução

A pasta `docs/` reúne a documentação técnica, especificações de game design, arquitetura de software e planejamento visual do jogo **pokeIF**.

Desenvolver um jogo orientado a objetos exige um alinhamento detalhado entre as regras do jogo e a estrutura do código. Este diretório centraliza os diagramas formais em UML (como o mapeamento das classes de entidades e cenários), apresentações acadêmicas para o **IFCE Campus Maranguape** e todo o estudo de interface e experiência do utilizador (UI/UX) focado na estética retrô de jogos 2D.

---
