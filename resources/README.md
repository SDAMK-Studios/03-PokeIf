# 🎨 Recursos Visuais e Estáticos (`resources/`)

## 📌 Introdução

A pasta `resources/` é dedicada ao armazenamento de todos os **ativos estáticos e visuais** utilizados na construção da Interface Gráfica do Usuário (GUI) do módulo **PokeIf**.

Separar os componentes de mídia (como ícones, logotipos e ilustrações) do código-fonte em Java é uma boa prática essencial de arquitetura de software. Isso garante maior organização do projeto, facilita a manutenção de estilo, melhora a reutilização de componentes visuais e previne o acoplamento direto de caminhos (*hardcoding*) dentro das classes da aplicação.

---

## 📁 Estrutura de Diretórios

```text
resources/
│
├── README.md         # Documentação da pasta de recursos visuais
│
├── icons/         # Ícones utilizados nos botões, campos e menus
└── images/        # Imagens de fundo, logos, avatares e ilustrações
