# 💻 Código-Fonte ( src/ )

## 📌 Introdução

A pasta `src/` (do inglês *source*) centraliza todo o código-fonte em **Java** do jogo **pokeIF**.

Neste diretório reside a arquitetura orientada a objetos que suporta as mecânicas centrais da aplicação: loop principal do jogo, renderização gráfica, controle de colisão, sistema de duelos, navegação pelo mapa do **IFCE Campus Maranguape** e integração com o módulo de agenda. O código é estruturado de forma modular para garantir encapsulamento, reuso de classes e facilidade no isolamento de erros.
