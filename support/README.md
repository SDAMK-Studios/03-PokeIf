# 🛠️ Materiais de Apoio e Suporte ( support/ )

## 📌 Introdução

A pasta `support/` atua como um repositório auxiliar de conhecimento do projeto **pokeIF**.

O objetivo deste diretório é fornecer todo o suporte necessário tanto para novos desenvolvedores que venham a colaborar com o jogo quanto para estudantes e avaliadores do **IFCE Campus Maranguape**. A pasta centraliza documentações complementares, referências de pesquisa em *game design*, tutoriais de configuração do ambiente de desenvolvimento Java e gravações de demonstração do *gameplay*.

---

```text
support/

├── documents/                  # Documentos complementares, especificações e relatórios

├── tutorials/                  # Guias passo a passo para configuração do ambiente e execução
